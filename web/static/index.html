Инструкция пользователя

          
Полное руководство по работе с МонтажПро: от загрузки отчёта до записи в Excel.

        

      


      

        

          
Содержание

          
          
          
          
          
          
          
          
        


        

          

            
1. Типовой сценарий (вкладка «Отчёт»)

            
    
              
  1. 
                Дата отчёта. Укажите дату — по ней выбирается месяц Excel и дневной лист (01…31).
                Если файла месяца ещё нет, он создаётся из шаблона автоматически при записи.
              
    2. 
              
  2. 
                Загрузка данных. Перетащите файл (.txt, .doc, .docx, .xls, .xlsx, .csv), выберите файл, вставьте из буфера или наберите текст в поле.
              
    3. 
              
  3. 
                Разобрать через ИИ. Дождитесь распознавания. В предпросмотре появятся ФИО, работы, объёмы, тарифы и ЗП.
              
    4. 
              
  4. 
                Проверка. Красные строки — работа не найдена в прайсе (в денежный итог не входит). При необходимости поправьте JSON и нажмите «Пересчитать по прайсу».
              
    5. 
              
  5. 
                Формировать отчёт. Данные дописываются в книгу нужного месяца. Повтор той же даты + того же текста не запишется повторно (защита от дублей).
              
    6. 
            

            
Этапы сверху экрана (1→4) показывают, на каком шаге вы сейчас: загрузка → распознавание → расчёт → формирование.

          


          

            
2. Как писать текст отчёта

            
Чем понятнее текст, тем точнее разбор. Рекомендуемый вид:


Слободянюк, Чуприков
1 заявка по неисправности интернета
СНТ Победа 255
3 выкладки запаса кабеля
2 муфты монтаж
Перекидка кабеля между зданиями 30 м
19 сварок 1-7
2 обжима RJ-45

            
Бригада и один человек

            
    
              
  • Несколько фамилий через запятую, «и» или пробел в начале блока = одна бригада: работы пишутся один раз, ЗП делится поровну.
    • 
              
  • Отдельные блоки работ на разных людей — указывайте явно, например: Иванов: и дальше его работы.
    • 
              
  • Фамилии лучше брать из штатного списка (вкладка «Настройки» → Сотрудники).
    • 
            

            
Объёмы

            
    
              
  • Число в начале строки: 3 выкладки запаса кабеля → 3 шт.
    • 
              
  • Число в конце с единицей: … 30 м → 30 м.
    • 
              
  • Диапазон в названии — не объём: 19 сварок 1-7 → объём 19, в названии остаётся «1-7».
    • 
              
  • Не считаются объёмом: мм, кг, адреса (Калинина 49 бр), заголовки вроде «1 заявка по…», слово «Ремонт» без числа работ.
    • 
              
  • Несколько работ в одной строке лучше разносить на отдельные строки.
    • 
            

            
Тип услуги

            
Если в тексте есть разделы «Заявки по ТВ» / «Заявки по интернету», тип услуги подставится по разделу. Иначе обычно «Общее».

            
Поле «Доп. инструкция для ИИ» — необязательно; можно уточнить, например: «имена писать как в штатном списке».

          


          

            
3. Предпросмотр и правка

            
    
              
  • Таблица справа: ФИО, наименование, количество, тариф, ЗП.
    • 
              
  • Строка «Итого» — сумма по отчёту (без ненайденных в прайсе работ).
    • 
              
  • Блок «Проблемные работы» внизу — что не сопоставилось с прайсом; добавьте работу в прайс или алиас и пересчитайте.
    • 
              
  • «JSON от нейросети» — можно править вручную, затем «Пересчитать по прайсу».
    • 
              
  • «Отмена» сбрасывает текущий предпросмотр в этой сессии.
    • 
            

            
Расчёт в интерфейсе идёт по JSON-прайсу (data/price_list.json). В Excel тарифы берутся с листа «Данные» книги — держите их согласованными.

          


          

            
4. Запись в Excel

            
    
              
  • Кнопка «Формировать отчёт» дописывает блок на дневной лист (число даты = имя листа 01…31).
    • 
              
  • Месяц выбирается по дате отчёта, файл: data/workbooks/SE_Lukhovitsy_ГГГГ-ММ.xlsx.
    • 
              
  • Если файла месяца нет — создаётся из шаблона и становится активным.
    • 
              
  • Бригада пишется одним блоком; в колонке на человека ЗП делится на число участников.
    • 
              
  • Дубликат (та же дата + тот же текст отчёта) повторно не записывается.
    • 
              
  • Скачать текущую активную книгу: «Настройки» → «Скачать Excel».
    • 
            

          


          

            
5. Прайс и алиасы работ

            
Прайс

            
    
              
  • Вкладка «Прайс»: наименование, цена, единица, тип (Интернет / ТВ / Комбо / Общее).
    • 
              
  • Тип «Общее» подходит к работам любого направления.
    • 
              
  • Изменения сохраняются в data/price_list.json. После правок пересчитайте отчёт.
    • 
            

            
Алиасы

            
    
              
  • Синонимы из живых отчётов → официальное имя из прайса.
    • 
              
  • Несколько синонимов в одной строке через ;.
    • 
              
  • Поиск работает и по официальному имени, и по синонимам.
    • 
              
  • Порядок сопоставления: синоним → точное имя → похожее название (порог сходства).
    • 
            

            
Если работа «красная» в предпросмотре — чаще всего нужен новый алиас или строка в прайсе.

          


          

            
6. Настройки

            
    
              
  • Новый месяц — создать пустую книгу на выбранный месяц из шаблона.
    • 
              
  • Существующие — выбрать книгу и «Сделать активным» (для скачивания и лога).
    • 
              
  • Запись отчёта всё равно идёт в месяц даты отчёта, даже если активна другая книга.
    • 
              
  • Сотрудники — по одному ФИО на строку; список подставляется в промпт ИИ для узнавания фамилий.
    • 
              
  • Модель — какая модель Ollama настроена и доступна ли служба.
    • 
            

          


          

            
7. Лог Excel

            
История успешных записей в активную книгу: дата, лист, сумма, сколько работ не найдено, время записи, идентификатор.

            
На вкладке «Отчёт» внизу также есть «История записей» за текущую сессию браузера.

          


          

            
8. Частые проблемы

            

              
Ошибка соединения с Ollama / таймаут

              
Запустите Ollama, убедитесь что модель скачана (ollama pull qwen2.5:3b), повторите разбор.


              
Неверные объёмы или «съехали» названия

              
Пишите объём явно (в начале строки или в конце с ед. изм.). Откройте JSON, поправьте volume / unit / raw_task_name, нажмите «Пересчитать по прайсу».


              
Работа красная / нет тарифа

              
Добавьте наименование в прайс или синоним на вкладке «Алиасы», сохраните, пересчитайте.


              
Не узнали фамилию

              
Добавьте ФИО в «Настройки → Сотрудники» и сохраните. Пишите фамилию как в списке.


              
Отчёт не записался / «уже записан»

              
Тот же текст на ту же дату уже есть в логе. Измените текст или дату, либо проверьте лог Excel.


              
Открылся не тот месяц в Excel

              
Проверьте поле «Дата отчёта» — месяц книги берётся из неё. Нужный файл ищите в data/workbooks/.


              
Суммы в UI и в Excel отличаются

              
В UI — прайс из JSON; в Excel — лист «Данные» книги. Синхронизируйте цены в обоих местах.
