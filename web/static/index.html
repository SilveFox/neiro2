1. Типовой сценарий (вкладка «Отчёт»)

            
    
              
  1. 
                Таблица Excel. В начале формы выберите месячную книгу (до даты отчёта). Она станет активной для скачивания и лога.
                Новую книгу с названием создайте заранее во вкладке «Настройки» (см. раздел «6. Новый месяц»).
              
    2. 
              
  2. 
                Дата отчёта. Укажите день — по нему выбирается дневной лист (01…31). Запись идёт в книгу месяца этой даты;
                если файла ещё нет, при «Формировать отчёт» создастся ГГГГ-ММ.xlsx без вашего названия.
              
    3. 
              
  3. 
                Загрузка данных. Перетащите файл (.txt, .doc, .docx, .xls, .xlsx, .csv), выберите файл, вставьте из буфера или наберите текст в поле.
              
    4. 
              
  4. 
                Разобрать через ИИ или Разобрать без ИИ.
                Без ИИ быстрее на CPU: ФИО в первой строке, объёмы явно («3 выкладки…» / «… 2 шт»). В предпросмотре — ФИО, работы, тарифы и ЗП.
              
    5. 
              
  5. 
                Проверка и правка. Красные строки — работа не найдена в прайсе (в денежный итог не входит).
                Ошибки ИИ (название, объём, ФИО и т.д.) правьте прямо в таблице предпросмотра, затем нажмите
                «Применить правки» (см. раздел «3. Предпросмотр и правка»).
              
    6. 
              
  6. 
                Формировать отчёт. Данные дописываются в книгу нужного месяца. Несохранённые правки из таблицы
                подхватываются автоматически. Повтор той же даты + того же текста не запишется повторно (защита от дублей).
              
    7. 
            

            
Этапы сверху экрана (1→4) показывают, на каком шаге вы сейчас: загрузка → распознавание → расчёт → формирование.

          


          

            
2. Как писать текст отчёта

            
Чем понятнее текст, тем точнее разбор. Рекомендуемый вид:


Слободянюк, Чуприков
1 заявка по неисправности интернета
СНТ Победа 255
3 выкладки запаса кабеля
2 муфты монтаж
Перекидка кабеля между зданиями 30 м
19 сварок 1-7
2 обжима RJ-45

            
Бригада и один человек

            
    
              
  • Несколько фамилий через запятую, «и» или пробел в начале блока = одна бригада: работы пишутся один раз, ЗП делится поровну.
    • 
              
  • Отдельные блоки работ на разных людей — указывайте явно, например: Иванов: и дальше его работы.
    • 
              
  • Фамилии лучше брать из штатного списка (вкладка «Настройки» → Сотрудники).
    • 
            

            
Объёмы

            
    
              
  • Число в начале строки: 3 выкладки запаса кабеля → 3 шт.
    • 
              
  • Число в конце с единицей: … 30 м → 30 м.
    • 
              
  • Диапазон в названии — не объём: 19 сварок 1-7 → объём 19, в названии остаётся «1-7».
    • 
              
  • Не считаются объёмом: мм, кг, адреса (Калинина 49 бр), заголовки вроде «1 заявка по…», слово «Ремонт» без числа работ.
    • 
              
  • Несколько работ в одной строке лучше разносить на отдельные строки.
    • 
            

            
Тип услуги

            
Если в тексте есть разделы «Заявки по ТВ» / «Заявки по интернету», тип услуги подставится по разделу. Иначе обычно «Общее».

            
Поле «Доп. инструкция для ИИ» — необязательно; можно уточнить, например: «имена писать как в штатном списке».

          


          

            
3. Предпросмотр и правка

            

              После разбора справа показывается редактируемая таблица. Основной способ исправить ошибки ИИ —
              править ячейки здесь, а не в JSON. Повторный вызов нейросети для этого не нужен.
            


            
Что видно в таблице

            
    
              
  • ФИО — сотрудник или бригада (через запятую). Правка ФИО на одной строке синхронизируется со всеми работами этого блока.
    • 
              
  • Наименование работы — формулировка для сопоставления с прайсом и алиасами. Под полем может отображаться «→ официальное имя из прайса», если сопоставление уже нашлось.
    • 
              
  • Кол-во и Ед. — объём и единица (шт, м, км, ч…).
    • 
              
  • Тип — Общее, Интернет, ТВ или Комбо (влияет на выбор позиции прайса).
    • 
              
  • Тариф и ЗП — только для чтения; обновляются после пересчёта. Красная строка = не найдено в прайсе, в «Итого» не входит.
    • 
              
  • Итого под таблицей — сумма по отчёту без ненайденных работ.
    • 
            


            
Как править работы в предпросмотре

            
    
              
  1. Щёлкните нужную ячейку и измените значение (ФИО, название, кол-во, ед., тип).
    2. 
              
  2. 
                Управление строками:
                
      
                  
    • ✕ — удалить работу;
      • 
                  
    • + (в конце блока сотрудника) — добавить пустую работу;
      • 
                  
    • если у сотрудника нет работ — кнопка «+ работа».
      • 
                
    
              
    3. 
              
  3. 
                Нажмите «Применить правки» (или Enter в поле) —
                изменения запишутся во внутренний JSON и выполнится пересчёт по прайсу без повторного вызова ИИ.
              
    4. 
              
  4. Проверьте тарифы, ЗП и «Итого». При необходимости повторите правку.
    5. 
            

            

              Подсказка под таблицей напомнит, если есть несохранённые правки.
              Перед «Формировать отчёт», «Пересчитать по прайсу» и «Сохранить в БД» правки из таблицы подхватываются сами,
              даже если «Применить правки» не нажимали.
            


            
Проблемные (красные) работы

            
    
              
  1. Внизу вкладки «Отчёт» откройте блок «Проблемные работы».
    2. 
              
  2. Найдите нужную позицию в прайсе (поиск + список) и нажмите «Выбрать».
    3. 
              
  3. Формулировка из отчёта сохранится в алиасы, затем выполнится пересчёт — строка должна стать обычной (с тарифом).
    4. 
              
  4. 
                Если позиции в прайсе ещё нет — добавьте её на вкладке «Прайс», затем снова «Применить правки» / «Пересчитать по прайсу»
                или привяжите через «Проблемные работы».
              
    5. 
            


            
Кнопки под предпросмотром

            
    
              
  • Применить правки — таблица → JSON + пересчёт.
    • 
              
  • Формировать отчёт — запись в Excel (месячная книга / дневной лист).
    • 
              
  • Отмена — сброс текущего предпросмотра в этой сессии (правки и JSON очищаются).
    • 
            


            
JSON от нейросети (дополнительно)

            

              Блок под таблицей — запасной редактор «как есть» от модели. Нужен для редких случаев
              (тонкая правка структуры, просмотр сырых полей). Обычные исправления делайте в таблице.
            

            
    
              
  • Пересчитать по прайсу — пересчёт текущего JSON без вызова ИИ.
    • 
              
  • Сохранить в БД — архив разбора и расчёта в SQLite (data/reports.db), Excel не заменяет.
    • 
            

            
Расчёт в интерфейсе идёт по JSON-прайсу (data/price_list.json). В Excel тарифы при записи берутся из того же расчёта; лист «Данные» книги лучше держать согласованным с прайсом.

          


          

            
4. Запись и скачивание Excel

            
    
              
  • Перед записью удобно проверить и поправить работы в предпросмотре («Применить правки»). Несохранённые правки из таблицы при «Формировать отчёт» подхватываются сами.
    • 
              
  • Кнопка «Формировать отчёт» дописывает блок на дневной лист (число даты = имя листа 01…31).
    • 
              
  • В интерфейсе таблица показывается как ГГГГ-ММ или ГГГГ-ММ — название. На диске: data/workbooks/<название>_ГГГГ-ММ.xlsx.
    • 
              
  • Если файла месяца нет — создаётся из шаблона и становится активным.
    • 
              
  • Бригада пишется одним блоком; в колонке на человека ЗП делится на число участников.
    • 
              
  • Дубликат (та же дата + тот же текст отчёта) повторно не записывается.
    • 
              
  • Активную книгу выбирают в «Отчёте» (поле «Таблица Excel»).
    • 
            


            
Скачивание таблицы

            
На вкладке «Настройки» → блок «Заполнить или изменить таблицу»:

            
    
              
  1. Выберите нужную книгу в списке и при необходимости нажмите «Сделать активной».
    2. 
              
  2. 
                Скачать таблицу — выгрузка полной активной книги со всеми листами
                (01…31, «Данные», «Расчет», «Шаблон» и т.д.), как файл лежит на сервере.
              
    3. 
              
  3. 
                Скачать за период — укажите даты с и по, затем нажмите кнопку.
                Период должен лежать внутри месяца активной книги (нельзя захватить другой месяц одной кнопкой).
              
    4. 
            

            
Что попадает в файл «за период»

            
    
              
  • Только дневные листы выбранных дат — например с 5 по 12 октября → листы 05…12.
    • 
              
  • Не включаются вкладки «Данные», «Расчет» и «Шаблон».
    • 
              
  • Листы дней вне диапазона тоже не копируются.
    • 
              
  • 
                Имя файла на компьютере: <имя_книги>_ДД-ДД.xlsx,
                например Гарантия_2026-10_05-12.xlsx.
              
    • 
            

            

              Такой файл удобно отдавать «на руки» за конкретные дни смены: без прайса и расчётного листа, только заполненные дни.
              Исходная книга на сервере при скачивании не меняется.
            

          


          

            
5. Прайс и алиасы работ

            
Прайс

            
    
              
  • Вкладка «Прайс»: наименование, цена, единица, тип (Интернет / ТВ / Комбо / Общее).
    • 
              
  • Тип «Общее» подходит к работам любого направления.
    • 
              
  • Изменения сохраняются в data/price_list.json. После правок пересчитайте отчёт.
    • 
            

            
Алиасы

            
    
              
  • Синонимы из живых отчётов → официальное имя из прайса.
    • 
              
  • Несколько синонимов в одной строке через ;.
    • 
              
  • Поиск работает и по официальному имени, и по синонимам.
    • 
              
  • Порядок сопоставления: синоним → точное имя → похожее название (порог сходства).
    • 
            

            

              Если работа «красная» в предпросмотре — выберите позицию из прайса в блоке проблемных работ (алиас создаётся сам),
              поправьте название в таблице и нажмите «Применить правки», либо добавьте новую строку на вкладке «Прайс».
            

          


          

            
6. Создание нового месяца (файла Excel)

            
Новую пустую месячную книгу создают на вкладке «Настройки», блок «Создать новую таблицу». Файл появляется в каталоге data/workbooks/ и сразу становится активным.


            
Пошагово

            
    
              
  1. Откройте вкладку «Настройки».
    2. 
              
  2. В блоке «Создать новую таблицу» выберите месяц (поле «Месяц новой таблицы», формат ГГГГ-ММ).
    3. 
              
  3. 
                Введите название файла — как будет называться книга на диске.
                Примеры: Гарантия, Луховицы, Север.
                Пробелы и спецсимволы заменятся на _.
              
    4. 
              
  4. Нажмите «Создать новую таблицу».
    5. 
              
  5. В списке таблиц появится запись вида 2026-11 — Гарантия; на диске файл: Гарантия_2026-11.xlsx.
    6. 
              
  6. Дальше заполняйте отчёты на вкладке «Отчёт» (дата дня → лист 01…31) и нажимайте «Формировать отчёт».
    7. 
            


            
Как называется файл

            
    
              
  • С названием: <название>_ГГГГ-ММ.xlsx — например Гарантия_2026-11.xlsx.
    • 
              
  • Без названия: только ГГГГ-ММ.xlsx — например 2026-11.xlsx.
    • 
              
  • В списках UI: ГГГГ-ММ или ГГГГ-ММ — название.
    • 
              
  • На один месяц можно создать несколько файлов с разными названиями (разные объекты / бригады).
    • 
            


            
После создания

            
    
              
  • Сделать активной — выбрать таблицу в списке и нажать кнопку (или выбрать её на вкладке «Отчёт»).
    • 
              
  • Скачать таблицу — полная выгрузка активной книги на компьютер.
    • 
              
  • Скачать за период — только дневные листы выбранных дат (см. «Скачивание таблицы» в §4).
    • 
              
  • Изменить / дозаполнить — переход в «Отчёт» для разбора текста и записи в Excel.
    • 
              
  • Если при «Формировать отчёт» файла месяца даты ещё нет, система создаст ГГГГ-ММ.xlsx автоматически (без вашего названия). Чтобы имя было своим — создайте книгу заранее в «Настройках».
    • 
            

          


          

            
7. Настройки

            
    
              
  • Создать новую таблицу — см. раздел «6. Создание нового месяца»: месяц + название → файл <название>_ГГГГ-ММ.xlsx.
    • 
              
  • 
                Заполнить или изменить таблицу — выбрать книгу в списке (ГГГГ-ММ или ГГГГ-ММ — название):
                сделать активной, скачать целиком, скачать за период (даты «с»…«по» → только листы дней, без «Данные»/«Расчет»/«Шаблон»)
                или перейти к дозаписи в «Отчёте». Подробнее — §4, скачивание.
              
    • 
              
  • Тот же выбор таблицы доступен на вкладке «Отчёт» перед датой. Запись идёт в книгу месяца даты отчёта (или в уже выбранную активную с тем же месяцем).
    • 
              
  • Модель ИИ — выбор модели Ollama (список + ручной ввод); сохраняется и сразу используется при разборе.
    • 
              
  • Сотрудники — по одному ФИО на строку; список подставляется в промпт ИИ для узнавания фамилий.
    • 
            

          


          

            
8. Лог Excel

            
История успешных записей в активную книгу: дата, лист, сумма, сколько работ не найдено, время записи, идентификатор.

            
На вкладке «Отчёт» внизу также есть «История записей» за текущую сессию браузера.

          


          

            
9. Частые проблемы

            

              
Ошибка соединения с Ollama / таймаут

              
Запустите Ollama, убедитесь что модель скачана (ollama pull qwen2.5:3b), повторите разбор.


              
Неверные объёмы или «съехали» названия

              

                Пишите объём явно в исходном тексте (в начале строки или в конце с ед. изм.).
                Уже после разбора правьте кол-во / ед. / наименование в таблице предпросмотра и нажмите
                «Применить правки» (JSON править не обязательно).
              


              
Работа красная / нет тарифа

              

                В «Проблемных работах» выберите позицию из прайс-листа — синоним уйдёт в алиасы, отчёт пересчитается.
                Либо исправьте название в таблице предпросмотра и снова «Применить правки».
                Новую строку прайса добавляйте только если такой работы ещё нет.
              


              
Не узнали фамилию / неверное ФИО в таблице

              

                Поправьте поле ФИО в предпросмотре и нажмите «Применить правки».
                Чтобы ИИ узнавал фамилию стабильнее — добавьте её в «Настройки → Сотрудники» и сохраните.
              


              
Добавил/удалил работу в таблице, а итог не изменился

              
Нажмите «Применить правки» (или Enter в ячейке). Пока кнопка активна / подсказка говорит о несохранённых правках — пересчёт ещё не выполнен.


              
Отчёт не записался / «уже записан»

              
Тот же текст на ту же дату уже есть в логе. Измените текст или дату, либо проверьте лог Excel.


              
Открылся не тот месяц в Excel

              
На вкладке «Отчёт» выберите нужную таблицу и проверьте «Дату отчёта» — запись идёт в месяц этой даты. Файлы: data/workbooks/.


              
«Таблица уже существует»

              
Для этого месяца и названия файл уже есть. Выберите другое название, другой месяц или активируйте существующую книгу в списке.


              
Файл создался без моего названия (только ГГГГ-ММ.xlsx)

              
Так бывает при автосоздании по дате отчёта. Задайте название заранее: «Настройки» → «Создать новую таблицу» → поле «Название файла».


              
Не скачивается период / ошибка про месяц книги

              

                Даты «с» и «по» должны быть внутри месяца активной книги.
                Сначала выберите нужную таблицу и «Сделать активной», затем укажите дни этого месяца.
                В выгрузке за период нет вкладок «Данные» и «Расчет» — это нормально; для полной книги используйте «Скачать таблицу».
              


              
В скачанном за период файле нет прайса / листа «Расчет»

              

                Так задумано: период отдаёт только дневные листы. Прайс и расчёт остаются в полной книге на сервере
                и в полной выгрузке («Скачать таблицу»).
              


              
Суммы в UI и в Excel отличаются

              
В UI — прайс из JSON; в Excel — лист «Данные» книги. Синхронизируйте цены в обоих местах.
