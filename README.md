# Neiro — отчёты монтажников → JSON → расчёт → Excel

Система разбирает текстовые отчёты (Ollama), разделяет работы **по сотрудникам**, считает суммы по прайсу из книги SE Луховицы и **дописывает** данные в Excel за выбранный месяц.

## Книга Excel

Источник-шаблон: [`docs/SE_Lukhovitsy_iyun.xlsx`](docs/SE_Lukhovitsy_iyun.xlsx)

| Лист | Назначение |
|------|------------|
| **Данные** | Прайс: колонка B — наименование, C — цена (новое) |
| **Расчет** | Месячная сводка по сотрудникам (формулы с дневных листов) |
| **01…31** | Дневные отчёты; сюда дописываются блоки работ |
| **Шаблон** | Образец блока для пустого месяца |

### Месячные файлы

- Каталог: `data/workbooks/SE_Lukhovitsy_YYYY-MM.xlsx`
- Активная книга: `data/active_workbook.json`
- Лог дублей на книгу: `SE_Lukhovitsy_YYYY-MM.written.json`

В веб-интерфейсе: **«Создать пустой месяц»** (листы дней из «Шаблон», даты на «Расчет» на новый месяц) и **«Сделать активным»** для переключения.

Правило начисления: **один сотрудник → отдельный блок**, ЗП строки полностью ему (`I=H`).

## Установка

```bash
cd d:\Work\neiro
pip install -r requirements.txt
```

Нужен запущенный **Ollama** с моделью `qwen2.5:7b` (или смените `MODEL_NAME` в `core/config.py`).

## Веб-интерфейс

```bash
cd d:\Work\neiro
run_web.bat
```

или:

```bash
python run_web.py
```

Откройте http://127.0.0.1:8000

1. Создайте или выберите месяц Excel  
2. Вставьте отчёт и дату  
3. «Разобрать через ИИ» → при необходимости поправьте JSON в редакторе  
4. «Добавить в Excel» → «Скачать Excel»

JSON на диск не сохраняется — только в интерфейсе до записи в Excel.
